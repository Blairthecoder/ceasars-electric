FAQ

Frequently Asked Questions

Can you add recessed lighting to an existing ceiling?+
Yes. We install recessed and can lighting in existing ceilings, running new wiring and switching as needed with minimal disruption.
Do you install outdoor and security lighting?+
Yes, we install outdoor, landscape, and security lighting, including motion and dusk-to-dawn controls.
Are LED upgrades worth it?+
LED retrofits use far less energy, last much longer, and give you better light. They are one of the most cost-effective upgrades for most homes and businesses.
Can you install dimmers and smart switches?+
Yes, we wire dimmers, three-way switching, and smart controls so your lighting works exactly the way you want.
